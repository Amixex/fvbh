# Сервер Amix на Supabase (бесплатный тариф, без карты)

Регистрации нет. Сервер считает **7 дней бесплатно с первого запуска**, проверяет **лицензионные ключи** и **промокоды**.
Вся логика внутри базы (SQL-функции), ничего устанавливать на компьютер не нужно. Приложение видит только 4 функции;
таблицы недоступны снаружи.

## Шаг 1. Установка (один раз)
1. В панели Supabase (проект **Amix**) слева откройте **SQL Editor** → **New query**.
2. Откройте файл `schema.sql`, скопируйте всё содержимое, вставьте, нажмите **Run**. Должно появиться «Success. No rows returned».
3. Снова **New query**, вставьте `selftest.sql`, **Run**. Внизу появится таблица проверок: у каждой строки должно быть **ОК**
   (бесплатный период 7 дней, ключи, промокоды, защита от подбора, создание ровно 1000 уникальных кодов).
   Тест сам удаляет свои данные. Если есть «ОШИБКА» или красное сообщение, пришлите скриншот.

## Шаг 2. Свяжите приложение с проектом
Приложению нужны два значения (оба публичные, это нормально): **Project URL** и **publishable key**
(Project Settings → API Keys → Publishable key → кнопка копирования). Впишите их в файл
`app/src/main/res/values/config.xml` (строки `supabase_url` и `supabase_key`) и пересоберите приложение, либо пришлите их мне.
**Секретный ключ (secret) и пароль базы никому не показывайте и в приложение не вписывайте.**

## Шаг 3. Коды (файл `admin.sql`)
Команды вставляйте в SQL Editor по одной:
- `select * from amix.gen_promo(1000, 30, 0);` создаёт 1000 промокодов на 30 дней;
- `select * from amix.gen_keys(20, 'm1');` создаёт 20 ключей на месяц (`m1` 30 дней, `m6` 180, `m12` 365, `forever`);
- под результатом кнопка **Export → CSV** сохраняет список в файл для Excel (коды видите только вы);
- `select * from amix.v_licenses order by state, code;` показывает все ключи и кто что активировал;
- `select amix.revoke_code('keys', 'AMIX-...');` отзывает код.
Список кодов можно также открыть в **Table Editor**, выбрав схему `amix`.

## Шаг 4. Чтобы проект не засыпал
В GitHub-репозитории с приложением создайте файл `.github/workflows/keepalive.yml` (он лежит в проекте). Затем в репозитории:
Settings → Secrets and variables → Actions → **Variables** → создайте `SUPABASE_URL` и `SUPABASE_KEY` (те же два значения).
Раз в 3 дня сервер получит лёгкий запрос, и бесплатный проект не уснёт.

## Как работает защита
- 10 неудачных попыток активации за час блокируют устройство на час; 300 запросов в час и 30 новых устройств в час с одного адреса.
- Идентификаторы устройств и адреса хранятся только хэшами. Каждый код активируется один раз.
- Бесплатный период нельзя сбросить удалением данных приложения: идентификатор берётся из системы (ANDROID_ID) и не меняется при переустановке.
  Сброс до заводских настроек и модифицированное приложение (root) его обходят.

## Ограничения бесплатного тарифа
500 МБ базы (хватит на сотни тысяч устройств), проект засыпает без обращений (см. шаг 4). Доступность из России нужно проверить на мобильном
интернете без VPN: откройте `Project URL/rest/v1/` в браузере телефона, должно сразу показаться сообщение про API-ключ.
