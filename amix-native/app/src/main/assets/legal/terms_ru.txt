## 1. Предмет
Amix — мобильное приложение для Android с учебным ИИ-помощником, который работает на устройстве. Используя приложение, вы принимаете это соглашение.

Приложение предназначено для обучения. ИИ может ошибаться: проверяйте важные ответы, они не заменяют учителя, преподавателя или справочник.

## 3. Бесплатный период и PRO
- Бесплатный период — 7 дней (168 часов) с первого запуска приложения. В это время доступны все возможности PRO.
- Срок считает сервер, перезапуск и удаление данных приложения его не сбрасывают.
- После окончания периода для продолжения нужен лицензионный ключ или промокод.
- Ключ продаёт разработчик (Telegram: https://t.me/AmixAiOffline). Один ключ активируется один раз и действует на одном устройстве.

## 4. Что запрещено

- обходить ограничения: подменять идентификатор устройства, изменять приложение, подбирать ключи и промокоды;
- использовать Сервис для нарушения закона.
За нарушения лицензия может быть отключена.
