# Privacy Policy
_Version: [date]. Operator: [name], tax ID [ID], contact: [contact email]._

## 1. General
This policy describes what data the Amix mobile app for Android (the "Service") processes and how it is protected. The Service has no registration: no name, e-mail, phone number or password.

## 2. What data is processed
- Device identifier. The app creates it on the device. The server stores only its irreversible hash (SHA-256), the start date of the free period and the PRO expiry date.
- Information about activating a license key or promo code: the code itself, the activation date and the device hash.
- Technical request data. The IP address is used only to protect against abuse and is stored as a salted hash together with request counters.
- Data that stays on the device and is never transmitted: chat history, language and settings.

## 3. AI chats and microphone
Message texts are processed on the device: the AI model is built into the app and works offline. Messages are not sent to the Operator or third parties. The microphone is used only on the "Voice AI" screen for a visual effect. Audio is not recorded, stored or transmitted.

## 4. Purposes
- tracking the free period (7 days from the first launch);
- checking and activating license keys and promo codes;
- protection against code guessing and other abuse;
- user support.
