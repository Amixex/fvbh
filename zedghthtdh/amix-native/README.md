# Amix — нативное приложение

Kotlin + Jetpack Compose + Material 3, Hilt, Room, Navigation Compose, MediaPipe (модель внутри APK).
Эталон дизайна и поведения: ваш `index.html`; сверка в `PARITY.md`, эталонные кадры в `reference/screens/`.

## Что сделано
- Этап 1: инвентаризация (`PARITY.md`), эталонные кадры, дословные выдержки (`reference/`).
- Этап 2: каркас, тема из токенов веб-версии, строки RU/EN, меню, навигация, история в Room, ИИ из APK.
- Этап 5: «чёрная дыра» (`ui/BlackHole.kt`, порт формул из `reference/blackhole.js`), экран голоса
  (`ui/VoiceScreen.kt`), микрофон только как визуальный эффект (`ui/VoiceMeter.kt`).
- Этап 4 (сервер): 100 промокодов, функция активации `promo`, правила Firestore, тесты (см. `server/README.md`).
- Вход (Google через браузер + почта), аватарка, строка промокода на экране Pro, окно отчёта о сбоях. Что настроить в Firebase: `FIREBASE_SETUP.md`.

## Проверка промокодов
    node --test server/test/promo_parity.test.js

## Как обновить репозиторий на GitHub
Загрузите папку `app` и файл `build.gradle.kts` (Add file → Upload files). Папки `reference` и `server`
и файл `PARITY.md` можно не загружать (в них есть промокоды, не публикуйте их в открытом репозитории).
Старый `app/src/main/java/com/amix/tutor/ui/Theme.kt` не нужен (можно удалить, не мешает).
Файл `.github/workflows/build.yml` менять не нужно. APK появится в Releases.

## Обновление: таймеры, оплата, документы, анимации
- Таймеры: гость 24 часа, затем окно входа без возможности закрыть; аккаунт 7 дней, затем окно оплаты без возможности закрыть; плашка таймера и Pro в верхней панели.
- Тарифы Pro: 1 мес 200 ₽, 6 мес 900 ₽ (−25%), 12 мес 1500 ₽ (−37%), оплата через ЮKassa (сервер: `server/`, инструкция `server/README.md`).
- Документы открываются из меню «Конфиденциальность» и из «Настроек» (тексты в `app/src/main/assets/legal`).
- Переход между экранами с «засасыванием» в чёрную дыру (как в index.html) и заставка при запуске.
