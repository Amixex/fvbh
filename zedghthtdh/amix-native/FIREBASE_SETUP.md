# Что нужно сделать в Firebase, чтобы заработал вход

Приложение подписывается постоянным отладочным ключом (`app/amix-debug.p12`), поэтому отпечатки ниже
**не меняются** между сборками. Регистрируются один раз.

**SHA-1:**   `C0:0D:A1:71:23:6D:9F:73:B0:96:C8:E8:ED:0D:49:15:25:89:B6:47`
**SHA-256:** `0F:6C:B7:4C:14:4D:E7:2E:48:9E:DD:55:20:16:AB:68:A8:AB:66:0B:32:C1:3E:95:EB:B0:54:34:AA:69:6F:38`

## Шаги (5 минут)
1. Откройте console.firebase.google.com → ваш проект Amix → значок ⚙ → **Project settings**.
2. Вкладка **General**, блок **Your apps**, кнопка **Add app** → значок **Android**.
3. **Package name:** `com.amix.tutor` (именно так). Название любое (Amix). Нажмите **Register app**.
4. Добавьте оба отпечатка: **Add fingerprint** → вставьте SHA-1 → ещё раз **Add fingerprint** → вставьте SHA-256.
   Файл `google-services.json` скачивать не обязательно, шаги «Next» можно пропустить.
5. **Authentication → Sign-in method**: Google уже включён для сайта. Включите ещё **Email/Password** (запасной вход для телефонов без Google).
6. Удалите старое приложение Amix с телефона (подпись ключа изменилась), поставьте новый APK.

## Если вход пишет ERROR_INVALID_CERT_HASH
Это значит, что Firebase не узнал подпись приложения. Проверьте по порядку:
1. Приложение добавлено именно как **Android** (не Web) с именем пакета ровно `com.amix.tutor`.
2. В этом же приложении добавлены **оба** отпечатка (SHA-1 и SHA-256), без пробелов и опечаток.
3. Подождите 5 минут (Firebase применяет изменения не мгновенно) и попробуйте снова.
4. Самый надёжный вариант: на странице этого Android-приложения нажмите **google-services.json** (скачать)
   и загрузите файл в репозиторий по пути `app/google-services.json` (Add file → Upload files, папка `app`).
   Сборка подхватит его сама.

## Проверка
Верхний правый кружок (или «Войти» в меню) → «Продолжить с Google». Если вход не удался, в окне
появится строка «Подробности: …». Пришлите скриншот, по ней я пойму причину.

## Промокоды
Работают через серверную функцию `promo`: её нужно развернуть (инструкция в `server/README.md`:
тариф Blaze, `firebase deploy --only functions:promo`, затем загрузка 100 кодов скриптом seed).
Пока функция не развёрнута, при вводе кода будет сообщение об ошибке.

## Если приложение снова вылетит
При следующем запуске появится окно «Приложение завершилось с ошибкой» с отчётом. Нажмите «Скопировать»
или сделайте скриншот и пришлите мне.
